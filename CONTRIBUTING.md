# Contributions and ownership

Sightline is maintained by **Yousif Lubbad** under [LICENSE](LICENSE). Ask for
written approval before submitting outside code, assets, datasets, or model
weights. Public visibility and an issue or pull request do not grant reuse rights
or transfer copyright.

Before an outside contribution is accepted, the parties must agree on provenance,
integration rights, attribution, and any ownership transfer that is actually
intended. A separate valid agreement is required for a transfer. Do not label
someone else's work as Yousif Lubbad's property.

For authorized development:

- Write small, useful commits with accurate messages. Do not pad or backdate history.
- Use plain English comments that explain decisions, constraints, and failure cases.
- Keep owner notices on original files and applicable third-party notices intact.
- Submit only material you own or have permission to contribute. Keep secrets
  and private screenshots out of the repository.
- Keep models, test artifacts, local environments, and credentials out of Git.
- Run Ruff, mypy, pytest, and the package checks described in the README.
- Run mouse tests only against the project-owned demo in an isolated desktop.
- Report actual validation results and current limits. Do not invent benchmark numbers.

`.github/CODEOWNERS` requests Yousif's review when GitHub supports that workflow.
It is not a legal ownership transfer or a branch protection rule. Required reviews
and other repository protections must be configured separately when needed.

For permissions and provenance questions, use the contact details published on
[Yousif Lubbad's profile](https://github.com/YOUSIF-LUBBAD). Do not disclose private
security details in a public issue.
